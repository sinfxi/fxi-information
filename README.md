# اطلاعات FXI

داشبورد فارسی و واکنش‌گرا برای نمایش آمار بازیکن **fxi** در DDPER، با HTML/CSS/JavaScript خالص.

## امکانات
- نمایش آمار DDRace، Gores، FNG Standard و FNG Grenade
- تلاش برای دریافت داده از API عمومی DDPER و بروزرسانی دوره‌ای هر ۶۰ ثانیه
- نگهداری آخرین پاسخ موفق در localStorage
- تم روشن/تیره، طراحی واکنش‌گرا، نوار پیشرفت اسکرول و بازگشت به بالا
- پنجره درباره پروژه، لینک‌های سازنده و دکمه اشتراک‌گذاری
- بدون نیاز به نصب وابستگی یا build step

## اجرا
فایل `index.html` را باز کنید یا مخزن را روی میزبانی استاتیک قرار دهید.

## منبع داده
API عمومی مورد استفاده: `https://ddper.ir/api/player-profile/summary/fxi`

**محدودیت مهم:** بروزرسانی زنده به دسترس‌پذیری API و سیاست CORS آن وابسته است. اگر مرورگر اجازه دسترسی ندهد یا API در دسترس نباشد، سایت خطا را نشان می‌دهد و آخرین دادهٔ ذخیره‌شده/مقادیر پیش‌فرض را نگه می‌دارد. این پروژه همگام‌سازی آنی را تضمین نمی‌کند. برای اتصال پایدارتر، یک پراکسی سمت سرور لازم است.
